🎮 DS Game Hub Help

Loading games: Click Choose DS Game and select a .nds file from your device.

Controls: Use the emulator's gamepad/settings toolbar to view or change keyboard and controller mappings.

Touchscreen: Click on the lower DS screen using your mouse.

Screen layouts: After starting a game, open the emulator's advanced/RetroArch menu, then find Quick Menu → Core Options → Screen Layout. Look for Left/Right (side by side), Top/Bottom (stacked), or Hybrid/Top (focus mode). The exact menu path may vary by core version.

Saves: Save normally inside the game. The emulator also offers save states. Browser storage can be cleared, so keep backups if your progress matters.

Changing games: Use Change Game to reload the page and select another file.
